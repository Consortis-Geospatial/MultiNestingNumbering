# MultiNestingNumbering

## Overview

**MultiNestingNumbering** is a QGIS plugin designed to simplify the numbering of line features by generating unique codes that combine a user-defined prefix with a sequential number, reducing repetitive manual work and ensuring consistent feature identification.

## Features

* Generate unique codes using a user-defined prefix and sequential number.
* Support multiple users working simultaneously with different prefixes.
* Prevent duplicate codes across line features.
* Automate numbering and reduce manual work.

## Installation

Clone the repository into your local QGIS plugins directory:

```bash
git clone https://github.com/Consortis-Geospatial/MultiNestingNumbering.git
```

Alternatively, you can download or copy the plugin into the appropriate QGIS plugins directory.

## Usage

After installing the plugin:

1. Open **QGIS**.
2. Make sure the required layer is loaded.
3. Launch **MultiNestingNumbering** from the QGIS plugin interface.
4. Select the appropriate layer and configure the required options.
5. Run the plugin to apply the numbering to the selected line features.
